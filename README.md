# Linq AI Assistant

An AI-powered SMS assistant for small businesses. Customers text your Linq virtual number and receive instant, intelligent replies — generated by an LLM and sent back via the Linq API. Fully automated, 24/7, zero staff required.

Built for the **Linq Candidate Technical Challenge**.

---

## Demo

> Customer texts: `"What are your business hours?"`
>
> AI replies: `"We're open Mon-Fri 9am-6pm, Sat 10am-4pm. Closed Sundays!"`

The full loop — text received, AI generates response, SMS sent back — completes in under 3 seconds.

## How It Works

```
Customer SMS
     ↓
Linq virtual number
     ↓
Webhook POST → /api/webhook
     ↓
OpenRouter LLM generates reply
     ↓
Linq API sends SMS back
     ↓
Customer receives reply
```

1. Customer texts your Linq number
2. Linq fires a `message.received` webhook to your backend
3. Your Next.js API route parses the payload, extracts the message and sender phone
4. OpenRouter routes the message to an LLM with a business-tuned system prompt
5. The AI reply is sent back as an SMS via the Linq API

## Local Setup

### 1. Clone the repo

```bash
git clone https://github.com/SairamVarma07/linq-ai-assistant.git
cd linq-ai-assistant
```

### 2. Install dependencies

```bash
npm install
```

### 3. Create environment variables

Create a file named `.env.local` in the root of the project:

```bash
touch .env.local
```

Add the following variables:

```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
LINQ_API_TOKEN=your_linq_api_token_here
LINQ_PHONE_NUMBER=+1xxxxxxxxxx
```

| Variable | Where to get it |
|---|---|
| `OPENROUTER_API_KEY` | [openrouter.ai/keys](https://openrouter.ai/keys) - free, no credit card needed |
| `LINQ_API_TOKEN` | Linq Dashboard → Overview → Your API Token |
| `LINQ_PHONE_NUMBER` | Your Linq sandbox virtual number (e.g. `+16504687784`) |

### 4. Start the dev server

```bash
npm run dev
```

Your app runs at `http://localhost:3000`

### 5. Expose localhost with ngrok

Open a second terminal:

```bash
ngrok http 3000
```

Copy the forwarding URL — it looks like:
```
https://abc123.ngrok-free.app
```

### 6. Configure the Linq webhook

1. Go to [dashboard.linqapp.com/sandbox](https://dashboard.linqapp.com/sandbox) → **Webhooks**
2. Click **Edit** on your existing webhook (or **Create Webhook**)
3. Set the **Webhook URL** to:
   ```
   https://abc123.ngrok-free.app/api/webhook
   ```
4. Under **Events**, select only: `message.received`
5. Under **Phone Lines**, select your virtual number
6. Click **Save Changes**

### 7. Test it

Text your Linq number from your phone:

```
What are your business hours?
```

You should receive an AI-generated SMS reply within a few seconds.

## Webhook Handler

The webhook endpoint at `/api/webhook` handles all incoming Linq events:

```typescript
// Ignores outbound messages to prevent reply loops
if (body?.data?.direction === "outbound") {
  return Response.json({ success: true, ignored: true });
}

// Extracts message and sender from Linq v3 payload
const incomingMessage = body?.data?.parts?.[0]?.value;
const senderPhone = body?.data?.sender_handle?.handle;

// Calls OpenRouter LLM
const completion = await openai.chat.completions.create({
  model: "openai/gpt-oss-20b:free",
  messages: [{ role: "system", content: "..." }, { role: "user", content: incomingMessage }],
});

// Sends reply via Linq API
await axios.post("https://api.linqapp.com/api/partner/v3/chats", {
  from: process.env.LINQ_PHONE_NUMBER,
  to: [senderPhone],
  message: { parts: [{ type: "text", value: aiReply }] },
});
```

## Deploying to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**
3. Import your `linq-ai-assistant` repo
4. Add your environment variables in the Vercel dashboard:
   - `OPENROUTER_API_KEY`
   - `LINQ_API_TOKEN`
   - `LINQ_PHONE_NUMBER`
5. Click **Deploy**
6. Update your Linq webhook URL to your Vercel domain:
   ```
   https://your-app.vercel.app/api/webhook
   ```

## Changing the AI Model

The model is set in `src/app/api/webhook/route.ts`. Any model available on [openrouter.ai/models](https://openrouter.ai/models) works — just swap the model string:

```typescript
model: "openai/gpt-oss-20b:free",      // current
model: "meta-llama/llama-3.3-70b-instruct:free",  // smarter, still free
model: "google/gemma-4-31b-it:free",   // Google's free model
```

## Customising the AI Behaviour

Edit the system prompt in `src/app/api/webhook/route.ts` to match your business:

```typescript
{
  role: "system",
  content:
    "You are a helpful SMS assistant for [Your Business Name]. " +
    "Hours: Mon-Fri 9am-6pm. Address: 123 Main St. " +
    "Services: [list your services]. " +
    "Keep replies under 160 characters.",
}
```
